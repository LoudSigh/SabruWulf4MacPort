# Sabre Wulf: ZX Spectrum 48K analysis and native Apple port

Status: implementation specification; a rights-safe three-platform app prototype exists. Two user-captured `.z80` files provide **verified 48K menu and in-game screen/RAM states**, with 4,558 changed RAM bytes between them. A user-supplied SkoolKit reference led to independently validated 16×16 world layout, 48 reusable room records, a 196-entry sprite pointer table and 153 bounded sprite records; two bitmap masks have been privately checked pixel-for-pixel. See [external-reference.md](./docs/external-reference.md). The apps import the private world for exploration and replay scrubbing; the main interactive game remains a 2×2 placeholder. Six bounded input replays match the unmodified reference emulator at frames 40 and 100 for display hashes and actor state in one room. Reference-relative CPU stepping reproduces **every RAM frame** in those 180- and 200-frame paths and in a 256-frame west schedule; the previous RNG/enemy difference resulted from frame-boundary drift. The shared `CapturedMovementState` matches 980 bounded room/X/Y checkpoints using measured acceleration, friction and static collision, but its west/east passage still follows the legacy static path, not the reference-timed enemy encounter. Dynamic actors, combat, items, most exits, tape equivalence and asset rights remain unverified. Do not claim the port is complete until the phase gates below are satisfied.
